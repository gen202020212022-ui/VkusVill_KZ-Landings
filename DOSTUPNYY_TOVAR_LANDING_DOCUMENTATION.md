## Источник данных (Excel)

### Структура Excel файла
- **Столбец A**: Артикул (ID товара)
- **Столбец B**: Категория (используется для группировки товаров)
- **Столбец C**: Подкатегория (не используется в текущей версии)
- **Столбец D**: Наименование
- **Столбец E**: Квант (количество единиц в упаковке)
- **Столбец F**: Цена Партнеру
- **Столбец G**: Срок годности (сутки)
- **Столбец H**: Вес (гр/мл)
- **Столбец I**: Ссылка на фото
- **Столбец M**: Остаток (количество товара на складе)

### Группировка товаров
- Товары группируются по **Категориям** (столбец B)
- Каждая категория отображается как отдельная карточка на главной странице
- При клике на категорию открывается список товаров этой категории

## Функциональность

### 1. Структура страниц

#### Главная страница (Категории)
- Отображает все категории товаров
- Каждая категория показывает количество товаров
- Информационный текст по центру:
  - "В корзину добавляется 1 квант"
  - "Для увеличения количества квантов в заказе, перейдите в корзину"

#### Страница товаров категории
- Заголовок с названием категории
- Кнопка "← Назад к категориям"
- Сетка товаров с карточками

#### Страница корзины
- Список товаров в корзине
- Управление количеством (кнопки +/-)
- Отображение доступного товара (остаток минус количество в корзине)
- Кнопка скачивания заказа в Excel

### 2. Карточка товара

Отображает следующую информацию:
- **Изображение товара** (или заглушка "Нет фото")
- **Название товара**
- **Остаток: X шт** (из столбца M)
- **Квант: X** (из столбца E)
- **Вес: X гр/мл** (из столбца H)
- **Срок годности: X сут** (из столбца G)
- **Цена** (форматированная с символом ₸)
- **Кнопка добавления в корзину**

### 3. Логика корзины

#### Добавление товара в корзину
- При добавлении товара в корзину добавляется **один квант** (значение из столбца E)
- Если товар уже есть в корзине, добавляется еще один квант
- Проверка остатка: нельзя добавить больше товара, чем есть на складе
- При попытке превысить остаток показывается предупреждение

#### Управление количеством в корзине
- Кнопка **"-"** уменьшает количество на один квант
- Кнопка **"+"** увеличивает количество на один квант
- Проверка остатка при увеличении количества
- При количестве 0 товар удаляется из корзины

#### Отображение доступного товара
- В корзине для каждого товара показывается "Доступный товар: X шт"
- Рассчитывается как: Остаток - Количество в корзине
- Если значение отрицательное, ячейка подсвечивается красным
- Если значение положительное, ячейка подсвечивается зеленым

#### Сохранение корзины
- Корзина сохраняется в `localStorage` браузера
- Данные сохраняются автоматически при каждом изменении
- При перезагрузке страницы корзина восстанавливается

### 4. Экспорт заказа

#### Формат файла
- **Формат**: Excel (.xlsx)
- **Библиотека**: SheetJS (xlsx.js) через CDN

#### Структура Excel файла
1. **Заголовки**: ID товара, Наименование, Цена за единицу, Количество, Квант, Сумма
2. **Данные товаров**: все товары из корзины с расчетом суммы
3. **Итоговая строка**: общее количество и общая сумма
4. **Дополнительная информация**:
   - Дата заказа
   - Клиент (Dokovil)

#### Название файла
- Формат: `Заказ_Dokovil_YYYY-MM-DD_HH-MM.xlsx`
- Пример: `Заказ_Dokovil_2025-01-23_14-30.xlsx`

### Основные функции JavaScript

1. **renderCategories()** - отображение категорий
2. **showCategory(categoryName)** - показ товаров категории
3. **renderProducts()** - отображение товаров категории
4. **addToCart(product)** - добавление товара в корзину (добавляет один квант)
5. **updateQuantity(productId, change)** - изменение количества в корзине (изменяет на один квант)
6. **removeFromCart(productId)** - удаление товара из корзины
7. **renderCart()** - отображение корзины
8. **updateCartStock()** - обновление остатков в корзине из актуальных данных
9. **getProductById(productId)** - получение товара по ID
10. **exportCartToFile()** - экспорт заказа в Excel
11. **formatPrice(price)** - форматирование цены с символом ₸
12. **saveCart()** - сохранение корзины в localStorage
13. **updateCartBadge()** - обновление бейджа корзины и итоговой суммы
14. **updateProductButtons()** - обновление состояния кнопок добавления в корзину

### Особенности реализации

#### Парсинг кванта
- Квант может быть в разных форматах: "6", "6 шт", "Квант: 6"
- Используется регулярное выражение для извлечения числа
- По умолчанию используется значение 1, если квант не указан

#### Проверка остатка
- При добавлении товара проверяется остаток
- При увеличении количества проверяется остаток
- Показывается предупреждение, если остаток недостаточен
- Остаток обновляется из актуальных данных при открытии корзины

#### Отображение доступного товара
- Рассчитывается динамически: Остаток - Количество в корзине
- Отрицательные значения подсвечиваются красным
- Положительные значения подсвечиваются зеленым
