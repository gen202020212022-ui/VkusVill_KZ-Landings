Улучшить визуальную эстетику лендингов, сделав их более запоминающимися и уникальными для каждого типа клиента, избегая типичной "AI-эстетики".

## 📋 Планируемые улучшения

### 1. Динамический выбор эстетики по типу клиента

**Текущее состояние:**
- Одинаковая цветовая схема для всех клиентов (зеленый ВкусВилл)
- Стандартные системные шрифты
- Одинаковый стиль для всех

**Планируется:**
- Параметр `--style` в `generate_landing.py`
- Предустановленные стили:
  - `luxury` - для салонов красоты (розовый + золотой)
  - `horeca` - для HoReCa (зеленый + оранжевый, максимализм)
  - `b2b` - для B2B оптовиков (темно-синий + аквамарин, минимализм)
  - `custom` - кастомная палитра

**Файлы для изменения:**
- `Inbox/generate_landing.py` - добавить параметр `--style` и стили
- HTML шаблон - использовать CSS переменные для цветов

---

### 2. Улучшенная типографика

**Текущее состояние:**
- Стандартные системные шрифты: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`
- Одинаковые шрифты для всех клиентов

**Планируется:**
- Подключение Google Fonts с кириллицей
- Разные шрифты для заголовков и текста
- Характерные display-шрифты вместо стандартных

**Примеры шрифтов:**
- **Люксовый:** Playfair Display (заголовки) + Inter (текст)
- **HoReCa:** Montserrat (заголовки) + Open Sans (текст)
- **B2B:** Space Grotesk (заголовки) + Inter (текст)

**Файлы для изменения:**
- HTML шаблон - добавить `<link>` для Google Fonts
- CSS - использовать переменные для шрифтов

---

### 3. Расширенные анимации

**Текущее состояние:**
- Базовые transition эффекты
- Простые hover эффекты

**Планируется:**
- Поэтапное появление товаров при загрузке (staggered animations)
- Плавные переходы между видами (категории → товары → корзина)
- Микро-взаимодействия (hover, click, добавление в корзину)
- Scroll-triggered анимации (если нужен скролл)

**Примеры:**
```css
/* Поэтапное появление товаров */
.product-card {
  opacity: 0;
  transform: translateY(20px);
  animation: fadeInUp 0.6s ease-out forwards;
}

.product-card:nth-child(1) { animation-delay: 0.1s; }
.product-card:nth-child(2) { animation-delay: 0.2s; }
.product-card:nth-child(3) { animation-delay: 0.3s; }
```

**Файлы для изменения:**
- HTML шаблон - добавить CSS анимации
- JavaScript - добавить классы для анимаций при загрузке

---

### 4. Улучшенная композиция

**Текущее состояние:**
- Стандартная сетка товаров (grid)
- Симметричная композиция
- Предсказуемый макет

**Планируется:**
- Асимметричные макеты
- Наложение элементов
- Featured товары (большие карточки)
- Диагональные акценты
- Элементы, нарушающие сетку

**Примеры:**
```css
/* Featured товар */
.product-card.featured {
  grid-column: span 2;
  transform: rotate(-1deg);
  box-shadow: 20px 20px 0 var(--accent);
}

/* Наложение */
.product-card.highlight {
  position: relative;
  z-index: 2;
  transform: scale(1.05);
}
```

**Файлы для изменения:**
- HTML шаблон - добавить классы `featured`, `highlight`
- CSS - улучшить grid композицию

---

### 5. Визуальные детали

**Текущее состояние:**
- Простые фоны
- Базовые тени
- Минимальные декоративные элементы

**Планируется:**
- Градиентные меши для фонов
- Текстуры и зерно (noise textures)
- Драматические тени
- Декоративные границы
- Геометрические паттерны
- Слоистые прозрачности

**Примеры:**
```css
/* Градиентный фон с паттерном */
.header {
  background: linear-gradient(135deg, var(--primary) 0%, var(--accent) 100%);
  position: relative;
  overflow: hidden;
}

.header::before {
  content: '';
  position: absolute;
  width: 200%;
  height: 200%;
  background: radial-gradient(circle, rgba(255,255,255,0.1) 1px, transparent 1px);
  background-size: 50px 50px;
  animation: movePattern 20s linear infinite;
}

/* Драматические тени */
.product-card {
  box-shadow: 
    0 4px 6px rgba(0,0,0,0.1),
    0 10px 20px rgba(0,0,0,0.05),
    0 20px 40px rgba(0,0,0,0.02);
}
```

**Файлы для изменения:**
- HTML шаблон - добавить псевдоэлементы и декоративные элементы
- CSS - улучшить визуальные детали

## 🚫 Что избегать

### Типичная "AI-эстетика":

1. ❌ **Переиспользуемые шрифты:** Inter, Roboto, Arial
2. ❌ **Клишированные цветовые схемы:** Фиолетовые градиенты, стандартные синие кнопки
3. ❌ **Предсказуемые макеты:** Стандартная сетка 3 колонки, центрированный контент
4. ❌ **Шаблонные дизайны:** Одинаковые для всех клиентов

### Вместо этого:

1. ✅ **Характерные шрифты** с кириллицей
2. ✅ **Уникальные палитры** под клиента
3. ✅ **Асимметрия, наложение, диагонали**
4. ✅ **Контекстно-специфичный характер**

## 🎯 Критерии успеха

**Запоминающийся лендинг должен:**

1. ✅ **Иметь четкую эстетическую концепцию** (не смешивать стили)
2. ✅ **Использовать характерные шрифты** (не стандартные)
3. ✅ **Иметь уникальную цветовую палитру** (под клиента)
4. ✅ **Иметь плавные анимации** (поэтапные появления, микро-взаимодействия)
5. ✅ **Использовать неожиданную композицию** (асимметрия, наложение)
6. ✅ **Иметь визуальные детали** (текстуры, тени, градиенты)
7. ✅ **Быть контекстно-специфичным** (под тип бизнеса клиента)
