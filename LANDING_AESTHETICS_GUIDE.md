# 🎨 Руководство по созданию запоминающихся лендингов

**Дата создания:** 2026-01-27  
**Источник:** Claude Code Skill - "Distinctive Frontend Interfaces"  
**Применение:** Проект генерации лендингов для B2B клиентов

---

## 📋 Краткое описание скилла

Этот скилл помогает создавать **запоминающиеся, production-grade интерфейсы**, которые избегают типичной "AI-эстетики" (скучные, шаблонные дизайны). Фокус на **смелых эстетических решениях** и **внимании к деталям**.

### Ключевая идея
> **"Что делает этот лендинг НЕЗАБЫВАЕМЫМ? Что запомнится клиенту?"**

---

## 🎯 Основные компоненты скилла

### 1. **Design Thinking (Дизайн-мышление)**

**Что это:** Процесс понимания контекста и выбора смелого эстетического направления ДО начала кодирования.

**Элементы:**
- **Purpose (Цель):** Какую проблему решает интерфейс? Кто его использует?
- **Tone (Тон):** Выбор экстремального эстетического подхода:
  - Минимализм
  - Максимализм
  - Ретро-футуризм
  - Органический стиль
  - Люксовый
  - Игривый
  - Редакционный
  - Брутализм
  - Ар-деко
  - Мягкий/пастельный
  - Индустриальный
- **Constraints (Ограничения):** Технические требования (фреймворк, производительность, доступность)
- **Differentiation (Дифференциация):** Что делает лендинг уникальным?

**Применение к проекту:**
- Для **салона красоты** (GARNET) → **Люксовый/мягкий** стиль (розовый, золотой, элегантность)
- Для **HoReCa** → **Индустриальный/максимализм** (яркие цвета, динамика, энергия)
- Для **B2B оптовиков** → **Минимализм/редакционный** (четкость, профессионализм, данные)

---

### 2. **Typography (Типографика)**

**Что это:** Выбор характерных, запоминающихся шрифтов вместо стандартных.

**Принципы:**
- Избегать: Inter, Roboto, Arial (слишком часто используются)
- Выбирать: Характерные display-шрифты + утонченные body-шрифты
- **Для русского языка:** Использовать кириллические шрифты

**Примеры для проекта:**
- **Люксовый стиль:** Playfair Display, Cormorant Garamond (кириллица)
- **Современный:** Manrope, Montserrat (кириллица)
- **Редакционный:** PT Serif, Merriweather (кириллица)
- **Брутализм:** Space Grotesk, IBM Plex Sans (кириллица)

**Применение:**
```css
/* Вместо стандартного */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto;

/* Использовать характерные шрифты */
@import url('https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;700&family=Inter:wght@300;400;600&display=swap');
font-family: 'Playfair Display', serif; /* для заголовков */
font-family: 'Inter', sans-serif; /* для текста */
```

---

### 3. **Color & Theme (Цвет и тема)**

**Что это:** Согласованная цветовая палитра с доминирующими цветами и резкими акцентами.

**Принципы:**
- Использовать CSS переменные для консистентности
- Доминирующие цвета + резкие акценты работают лучше, чем робкие палитры
- Избегать клишированных схем (фиолетовые градиенты)

**Применение к проекту:**

**Для салона красоты (GARNET):**
```css
:root {
  --primary: #d81b60; /* Розовый */
  --accent: #ffd700; /* Золотой */
  --text: #2c2c2c;
  --bg: #faf8f5; /* Теплый бежевый */
}
```

**Для HoReCa:**
```css
:root {
  --primary: #2dbe64; /* Зеленый ВкусВилл */
  --accent: #ff6b35; /* Оранжевый */
  --text: #1a1a1a;
  --bg: #f8f8f8;
}
```

**Для B2B оптовиков:**
```css
:root {
  --primary: #1e3a5f; /* Темно-синий */
  --accent: #00d4aa; /* Аквамарин */
  --text: #2c3e50;
  --bg: #ffffff;
}
```

---

### 4. **Motion (Движение и анимации)**

**Что это:** Анимации для эффектов и микро-взаимодействий.

**Принципы:**
- CSS-only для HTML
- Motion library для React (если используется)
- Оркестровка: поэтапные появления при загрузке страницы
- Scroll-triggered взаимодействия

**Применение к проекту:**

**Поэтапное появление товаров:**
```css
.product-card {
  opacity: 0;
  transform: translateY(20px);
  animation: fadeInUp 0.6s ease-out forwards;
}

.product-card:nth-child(1) { animation-delay: 0.1s; }
.product-card:nth-child(2) { animation-delay: 0.2s; }
.product-card:nth-child(3) { animation-delay: 0.3s; }

@keyframes fadeInUp {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

**Микро-взаимодействия:**
- Hover эффекты на карточках товаров
- Плавное добавление в корзину
- Анимация счетчика корзины
- Плавные переходы между видами (категории → товары → корзина)

---

### 5. **Spatial Composition (Пространственная композиция)**

**Что это:** Неожиданные макеты, асимметрия, наложение элементов, диагональные потоки.

**Принципы:**
- Неожиданные макеты
- Асимметрия
- Наложение элементов
- Диагональные потоки
- Элементы, нарушающие сетку
- Щедрое или контролируемое негативное пространство

**Применение к проекту:**

**Текущий подход (стандартная сетка):**
```css
.products-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 20px;
}
```

**Улучшенный подход (асимметрия, наложение):**
```css
.products-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 30px;
  /* Добавить наложение для некоторых карточек */
}

.product-card.featured {
  grid-column: span 2;
  transform: rotate(-1deg);
  box-shadow: 20px 20px 0 var(--accent);
}

.product-card.highlight {
  position: relative;
  z-index: 2;
  transform: scale(1.05);
}
```

---

### 6. **Backgrounds & Visual Details (Фоны и визуальные детали)**

**Что это:** Создание атмосферы через градиентные меши, текстуры, геометрические паттерны, слоистые прозрачности, драматические тени, декоративные границы, кастомные курсоры, зернистые наложения.

**Применение к проекту:**

**Градиентные меши:**
```css
.header {
  background: linear-gradient(135deg, var(--primary) 0%, var(--accent) 100%);
  position: relative;
  overflow: hidden;
}

.header::before {
  content: '';
  position: absolute;
  width: 200%;
  height: 200%;
  background: radial-gradient(circle, rgba(255,255,255,0.1) 1px, transparent 1px);
  background-size: 50px 50px;
  animation: movePattern 20s linear infinite;
}
```

**Текстуры и зерно:**
```css
body {
  background: var(--bg);
  position: relative;
}

body::after {
  content: '';
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background-image: url('data:image/svg+xml;base64,...'); /* Noise texture */
  opacity: 0.03;
  pointer-events: none;
  z-index: 1000;
}
```

**Драматические тени:**
```css
.product-card {
  box-shadow: 
    0 4px 6px rgba(0,0,0,0.1),
    0 10px 20px rgba(0,0,0,0.05),
    0 20px 40px rgba(0,0,0,0.02);
  transition: box-shadow 0.3s;
}

.product-card:hover {
  box-shadow: 
    0 8px 12px rgba(0,0,0,0.15),
    0 20px 40px rgba(0,0,0,0.1),
    0 40px 80px rgba(0,0,0,0.05);
}
```

## ❌ Что избегать

### Типичная "AI-эстетика":

1. **Переиспользуемые шрифты:**
   - ❌ Inter, Roboto, Arial
   - ✅ Характерные шрифты с кириллицей

2. **Клишированные цветовые схемы:**
   - ❌ Фиолетовые градиенты
   - ❌ Стандартные синие кнопки
   - ✅ Уникальные палитры под клиента

3. **Предсказуемые макеты:**
   - ❌ Стандартная сетка 3 колонки
   - ❌ Центрированный контент
   - ✅ Асимметрия, наложение, диагонали

4. **Шаблонные дизайны:**
   - ❌ Одинаковые для всех клиентов
   - ✅ Контекстно-специфичный характер

## 📝 Примеры применения

### Пример 1: Салон красоты (GARNET)

**Эстетика:** Люксовый, мягкий, элегантный

- Шрифты: Playfair Display (заголовки) + Inter (текст)

**Эстетика:** Максимализм, энергия, динамика

**Характеристики:**

- Цвета: Зеленый (#2dbe64) + Оранжевый (#ff6b35)

## 🎯 Критерии успеха

**Запоминающийся лендинг должен:**

1. ✅ **Иметь четкую эстетическую концепцию** (не смешивать стили)
2. ✅ **Использовать характерные шрифты** (не стандартные)
3. ✅ **Иметь уникальную цветовую палитру** (под клиента)
4. ✅ **Иметь плавные анимации** (поэтапные появления, микро-взаимодействия)
5. ✅ **Использовать неожиданную композицию** (асимметрия, наложение)
6. ✅ **Иметь визуальные детали** (текстуры, тени, градиенты)
7. ✅ **Быть контекстно-специфичным** (под тип бизнеса клиента)
