## 🔗 Формат ссылок

Все лендинги доступны по адресу:

```
https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/[имя-файла]
```

**Примеры:**
- `https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/arba-wine`
- `https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/dokovil`

## ✅ Готовность к использованию

**Итоговый результат создания лендинга:**

После успешного создания лендинга **ОБЯЗАТЕЛЬНО** должна быть выведена внешняя ссылка для клиента в формате:

```
🔗 Ссылка для клиента:
   https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/[имя-файла]
```

**Эта ссылка готова к отправке клиенту и работает для внешних пользователей.**
