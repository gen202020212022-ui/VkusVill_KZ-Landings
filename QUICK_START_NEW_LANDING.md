# 🚀 Быстрый старт: Создание нового лендинга

> **Для AI ассистента**: Используй эту инструкцию вместе с `LANDING_CREATION_GUIDE.md` для создания нового лендинга.

---

## 📋 Что нужно от пользователя:

1. **Excel файл** с товарами
2. **Название лендинга** (например: "HoReCa", "Остатки на складе B2B")
3. **Имя клиента** (для экспорта файлов)

---

## 🎯 Процесс создания:

### 1. Чтение Excel файла
- Найти файл по указанному пути
- Прочитать данные из Excel
- Определить структуру колонок

### 2. Преобразование в JSON
Создать структуру:
```javascript
const productsData = {
  "Категория 1": [
    {
      id: "84334",
      name: "Название товара",
      price: 1269.0,  // или 0 для "Цена по запросу"
      image: "https://...",
      quant: "12",  // опционально
      stock: 88  // опционально
    }
  ]
};
```

### 3. Создание HTML файла
Использовать структуру из `horeca.html` как шаблон:
- ✅ Встроенные CSS стили
- ✅ Встроенный JavaScript
- ✅ Три вида: категории → товары → корзина
- ✅ Функциональность корзины
- ✅ Экспорт в CSV/TXT файлы

### 4. Ключевые компоненты:

#### Корзина:
- `cart` - массив товаров в localStorage
- `saveCart()` - сохранение корзины
- `addToCart()` - добавление товара
- `removeFromCart()` - удаление товара
- `updateQuantity()` - изменение количества
- `renderCart()` - отображение корзины

#### Экспорт:
- `exportCartToFile()` - экспорт в CSV и TXT
- CSV с BOM для правильной кодировки
- Разделитель: точка с запятой (`;`)
- Имя файла: `Заказ_[Клиент]_[Дата_Время].csv`

### 5. Проверка:
- ✅ Корзина работает
- ✅ Экспорт работает
- ✅ Русские символы отображаются
- ✅ Адаптивный дизайн
