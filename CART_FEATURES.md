# 🛒 Функциональность корзины в лендингах

## ✅ Что добавлено:

1. **Иконка корзины** в правом верхнем углу заголовка
2. **Счетчик товаров** на иконке корзины
3. **Кнопка "В корзину"** на каждой карточке товара
4. **Вид корзины** с возможностью изменения количества
5. **Кнопка "Отправить заказ"** для формирования заказа
6. **Кнопка "Скачать заказ"** для экспорта корзины в файлы (CSV/Excel и TXT) ✅ НОВОЕ

---

## 🎯 Как это работает:

### Для клиента:

1. **Просмотр товаров:**
   - Открывает категорию
   - Видит товары с фото, названием, ценой и остатком

2. **Добавление в корзину:**
   - Нажимает кнопку "+ В корзину" на товаре
   - Кнопка меняется на "✓ В корзине" (красная)
   - Счетчик на иконке корзины обновляется

3. **Просмотр корзины:**
   - Нажимает на иконку корзины 🛒
   - Видит все добавленные товары
   - Может изменить количество (+/-)
   - Может удалить товар

4. **Экспорт заказа в файл:**
   - Нажимает "📥 Скачать заказ (Excel/CSV)"
   - Автоматически скачиваются два файла:
     - **CSV файл** (открывается в Excel) с разделителями точкой с запятой
     - **TXT файл** (текстовый формат) для удобного просмотра
   - Файлы содержат все данные заказа: ID товара, название, цена, количество, квант, сумма
   - Имя файла включает дату и время: `Заказ_HoReCa_2025-12-26_14-30.csv`

5. **Отправка заказа:**
   - Нажимает "Отправить заказ"
   - Видит подтверждение с деталями заказа
   - Корзина очищается

## 📥 Экспорт заказа в файлы

### Формат CSV файла:
- **Кодировка**: UTF-8 с BOM (правильно открывается в Excel с русскими символами)
- **Разделитель**: точка с запятой (`;`)
- **Столбцы**: ID товара; Наименование; Цена за единицу; Количество; Квант; Сумма
- **Итоги**: Общее количество товаров и общая сумма в конце файла

### Формат TXT файла:
- **Кодировка**: UTF-8
- **Структура**: Читаемый текстовый формат с нумерацией товаров
- **Информация**: Название, ID, цена, количество, квант (если есть), сумма по позиции
- **Итоги**: Общее количество товаров и общая сумма

### Особенности:
- ✅ Автоматическое имя файла с датой и временем
- ✅ Оба файла скачиваются автоматически при нажатии кнопки
- ✅ Правильная обработка товаров с ценой "по запросу"
- ✅ Корректное отображение русских символов в Excel
