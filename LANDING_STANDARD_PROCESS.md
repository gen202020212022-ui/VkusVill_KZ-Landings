## 📋 Обзор процесса

Когда пользователь предоставляет стандартный Excel файл с товарами, AI должен:

1. **Задать уточняющие вопросы** для получения необходимой информации
2. **Проверить структуру Excel файла** на соответствие стандарту
3. **Сгенерировать лендинг** с использованием скрипта `generate_landing.py`
4. **Загрузить на GitHub Pages** и предоставить готовую ссылку

---

## ❓ Стандартные уточняющие вопросы

### Обязательные вопросы (всегда задавать):

1. **Название компании/клиента**
   - Вопрос: "Какое название компании/клиента должно быть в заголовке лендинга?"
   - Примеры ответов: "HoReCa", "Остатки на складе B2B", "Доковил"
   - Использование: Отображается в заголовке `<h1>` и в метаданных заказа

2. **Короткое имя для URL** (опционально, но рекомендуется)
   - Вопрос: "Какое короткое имя использовать для URL? (например: 'horeca', 'ost-26dec', 'dokovil')"
   - Если не указано: Генерируется автоматически из названия компании
   - Использование: Имя файла на GitHub Pages (например: `horeca.html`)

### Дополнительные вопросы (если нужно):

3. **Кастомное сообщение в заголовке** (опционально)
   - Вопрос: "Нужно ли изменить текст под заголовком? (по умолчанию: 'В корзину добавляется 1 квант. Для увеличения количества квантов в заказе, перейдите в корзину')"
   - Если не указано: Используется стандартный текст

4. **Цветовая схема** (опционально)
   - Вопрос: "Нужна ли другая цветовая схема? (по умолчанию: зеленый #2dbe64)"
   - Если не указано: Используется стандартная зеленая схема

## 📊 Стандартная структура Excel файла

### Обязательные колонки:

1. **Категория** (столбец A или любой с названием "Категория")
   - Описание: Группировка товаров по категориям
   - Пример: "Консервация", "Бакалея", "Овощи. Фрукты. Грибы. Зелень"

2. **Наименование товара** (столбец B или любой с названием "Наименование товара", "Наименование", "Название")
   - Описание: Название товара
   - Пример: "Джем из киви", "Томаты черри"

3. **ID товара** (столбец C или любой с названием "ID")
   - Описание: Уникальный идентификатор товара
   - Пример: "84334", "91303"

### Опциональные колонки (используются по индексу, если есть):

4. **Квант** (столбец D или любой с названием "Квант", "Количество")
   - Описание: Количество товара в одной упаковке/кванте
   - Пример: "6", "12", "10"
   - Использование: При добавлении в корзину добавляется полный квант

5. **Срок годности (сутки)** (столбец F, индекс 5)
   - Описание: Срок годности в сутках
   - Пример: "90", "720", "365"
   - Отображается: "Срок годности: 90 сут"

6. **Вес, гр (Объём, мл)** (столбец G, индекс 6)
   - Описание: Вес в граммах или объем в миллилитрах
   - Пример: "310", "500 мл", "250 гр"
   - Отображается: "Вес: 310 гр" или "Вес: 500 мл"

7. **Стоимость товара в закупке, с НДС** (столбец H, индекс 7)
   - Описание: Цена за единицу товара
   - Пример: "1269", "500", "0" (0 = "Цена по запросу")
   - Отображается: "1 269 ₸" или "Цена по запросу"

8. **Ссылка на фото** (любой столбец с URL-ссылками)
   - Описание: URL изображения товара
   - Пример: "https://img.vkusvill.ru/pim/images/mobile/..."
   - Определение: Автоматически определяется по наличию URL (начинается с "http")
   - Отображается: Изображение товара или заглушка "Нет фото"

## 🎨 Особенности лендинга

### Функциональность:

1. **Категории товаров**
   - Отображение всех категорий из Excel
   - Счетчик товаров в каждой категории
   - Клик по категории открывает товары

2. **Карточки товаров**
   - Фото товара (если есть)
   - Название товара
   - Квант, вес, срок годности (если указаны)
   - Цена или "Цена по запросу"
   - Кнопка "В корзину" / "✓ В корзине"

3. **Корзина**
   - Квантовая логика: добавление всегда кратно кванту
   - Изменение количества: +/- изменяет на целый квант
   - Отображение: ID, Квант, Цена, Количество (шт), Сумма
   - Кнопка "Отправить заказ"

4. **Отправка заказа**
   - Сохранение в localStorage (резервная копия)
   - Отправка через n8n webhook в Google Sheets
   - Создание вкладки: "[Клиент] - [Дата]"
   - Подтверждение пользователю

### Дизайн:

- **Цветовая схема:** Зеленый (#2dbe64) - основной цвет, красный (#d7144b) - акцент
- **Адаптивность:** Работает на всех устройствах (компьютер, iPhone, Android, планшет)
- **Шрифты:** Системные шрифты (-apple-system, BlinkMacSystemFont, Segoe UI, Roboto)
- **Анимации:** Плавные переходы, hover-эффекты

## 🐛 Решение проблем

### Проблема: Файл не найден
**Решение:** Проверить путь к файлу, использовать абсолютный путь если нужно

### Проблема: Не найдены обязательные колонки
**Решение:** Проверить названия колонок в Excel, скрипт автоматически ищет варианты:
- "Наименование товара", "Наименование", "Название"
- "Категория"

### Проблема: Не загружается на GitHub
**Решение:** 
- Проверить git репозиторий: `cd landings && git status`
- Проверить права доступа к GitHub
- Проверить настройки GitHub Pages в репозитории

### Проблема: Не отображаются фото
**Решение:** 
- Проверить формат ссылок (должны начинаться с "http")
- Проверить доступность URL (некоторые могут требовать авторизации)
