# 📋 План реализации отправки заказов в Google Таблицу

## 🎯 Цель
Реализовать автоматическую отправку заказов из лендинга в Google Таблицу с созданием вкладок для каждого клиента.

## 📊 Требования

### Функциональные требования:
1. **Создание вкладки в Google Таблице** при отправке заказа
2. **Название вкладки**: `[Имя клиента] - [Дата]` (например: "HoReCa - 26.12.2025")
3. **Автоматическая запись даты создания** заказа
4. **Отдельный файл для каждого клиента** (или одна таблица с вкладками по клиентам)
5. **Структура данных заказа** в таблице

### Технические требования:
- Работа через Google Sheets API (gspread)
- Обработка ошибок и лимитов API
- Резервное сохранение в localStorage при ошибках

## 🏗️ Архитектура решения

### Вариант 1: Backend API (Рекомендуемый)
```
Лендинг (JavaScript) 
    ↓ HTTP POST
Backend API (Python Flask/FastAPI)
    ↓ gspread
Google Sheets API
    ↓
Google Таблица
```

**Плюсы:**
- ✅ Безопасность (credentials не в браузере)
- ✅ Контроль доступа
- ✅ Обработка ошибок на сервере
- ✅ Логирование

**Минусы:**
- ❌ Требует сервер
- ❌ Дополнительная инфраструктура

### Вариант 2: Прямое подключение (Простой)
```
Лендинг (JavaScript)
    ↓ fetch() к Google Apps Script
Google Apps Script (Web App)
    ↓
Google Sheets API
    ↓
Google Таблица
```

**Плюсы:**
- ✅ Не требует сервера
- ✅ Простая реализация
- ✅ Бесплатно

**Минусы:**
- ⚠️ Ограничения Google Apps Script
- ⚠️ Меньше контроля

### Вариант 3: Python скрипт через n8n (Гибридный)
```
Лендинг (JavaScript)
    ↓ HTTP POST webhook
n8n Workflow
    ↓ Execute Command
Python скрипт (send_order_to_sheets.py)
    ↓ gspread
Google Sheets API
    ↓
Google Таблица
```

**Плюсы:**
- ✅ Использует существующую инфраструктуру (n8n)
- ✅ Визуальный workflow
- ✅ Гибкость настройки

**Минусы:**
- ⚠️ Требует n8n

## 🔧 Реализация (Рекомендуемый вариант: Python скрипт)

### Шаг 1: Создать Python скрипт для отправки заказов

**Файл:** `Inbox/send_order_to_sheets.py`

**Функционал:**
1. Принимает JSON с данными заказа (через stdin или файл)
2. Подключается к Google Sheets через `google_sheets_helper.py`
3. Определяет файл клиента (или создает новый)
4. Создает вкладку с названием `[Клиент] - [Дата]`
5. Записывает данные заказа
6. Возвращает результат (успех/ошибка)

### Шаг 2: Настроить Google Таблицу

**Вариант A: Одна таблица для всех клиентов**
- ID таблицы хранится в конфиге
- Каждый клиент = отдельная вкладка
- Название вкладки: `[Клиент] - [Дата]`

**Вариант B: Отдельная таблица для каждого клиента**
- Создавать новую таблицу для каждого клиента
- Название файла: `Заказы - [Клиент] - [Дата]`
- Сложнее управление

**Рекомендация:** Вариант A (одна таблица с вкладками)

## ⚠️ Важные моменты

### Ограничения Google Sheets API:
- **60 запросов в минуту** на пользователя
- **300 запросов в 100 секунд**
- Использовать batch операции (`worksheet.update()` вместо множества `append_row()`)

### Обработка ошибок:
- Лимит API превышен → retry с экспоненциальной задержкой
- Нет доступа к таблице → сохранить в localStorage
- Ошибка сети → сохранить в localStorage, показать сообщение

### Безопасность:
- Не хранить credentials в коде лендинга
- Использовать OAuth2 токены
- Ограничить доступ к таблице только нужным пользователям
