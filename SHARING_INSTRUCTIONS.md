# Инструкция: Как делиться ссылками на лендинги

## 🎯 Цель
Получить рабочую ссылку на лендинг, которая открывается на:
- ✅ Компьютере (Windows, Mac, Linux)
- ✅ iPhone (Safari, Chrome)
- ✅ Android (Chrome, Firefox)
- ✅ Планшетах

---

## 📋 Текущая ситуация

### Проблема
GitHub Pages не настроен для репозитория, поэтому ссылки вида `https://username.github.io/repo/landings/file.html` не работают.

### Решение
Есть 3 варианта настройки:

---

## ✅ ВАРИАНТ 1: Настроить GitHub Pages (РЕКОМЕНДУЕТСЯ)

### Преимущества:
- ✅ Бесплатно
- ✅ Постоянные ссылки
- ✅ Автоматическое обновление при пуше
- ✅ Работает на всех устройствах

### Шаги настройки:

1. **Откройте настройки репозитория:**
   ```
   https://github.com/gen202020212022-ui/VkusVill_KZ-B2B/settings/pages
   ```

2. **Сделайте репозиторий публичным (если нужно):**
   - Перейдите в Settings → General → Danger Zone
   - Нажмите "Change visibility" → "Make public"
   - Подтвердите

3. **Вернитесь в Pages и настройте:**
   - В разделе "Source" выберите "Deploy from a branch"
   - Branch: `main`
   - Folder: `/ (root)`
   - Нажмите "Save"

4. **Подождите 1-2 минуты** пока GitHub обработает настройки

5. **Проверьте ссылку:**
   ```
   https://gen202020212022-ui.github.io/VkusVill_KZ-B2B/landings/остатки-на-складе-b2b-на-26-декабря-2025.html
   ```

### Формат ссылок после настройки:
```
https://gen202020212022-ui.github.io/VkusVill_KZ-B2B/landings/[имя-файла].html
```

---

## ✅ ВАРИАНТ 2: Использовать Netlify Drop (БЫСТРО, БЕЗ НАСТРОЙКИ)

### Преимущества:
- ✅ Работает сразу без настройки
- ✅ Не требует публичного репозитория
- ✅ Работает на всех устройствах

### Недостатки:
- ⚠️ Нужно загружать файлы вручную
- ⚠️ Ссылки меняются при каждой загрузке

### Шаги:

1. **Откройте Netlify Drop:**
   ```
   https://app.netlify.com/drop
   ```

2. **Перетащите HTML файл** из папки `landings/`

3. **Получите ссылку** вида:
   ```
   https://random-name-123.netlify.app
   ```

4. **Скопируйте ссылку** и делитесь ею

## ✅ ВАРИАНТ 3: Автоматическая загрузка на Netlify (ПРОДВИНУТЫЙ)

### Требуется:

## 🔧 Если GitHub Pages не работает

### Проверка:

1. **Проверьте настройки:**
   - Репозиторий должен быть публичным ИЛИ
   - У вас должен быть GitHub Enterprise

2. **Проверьте статус деплоя:**
   - В Settings → Pages должна быть зеленая галочка
   - Должен быть указан URL сайта

3. **Подождите:**
   - GitHub обрабатывает изменения 1-5 минут
   - Обновите страницу через минуту

### Альтернатива:
Используйте Вариант 2 (Netlify Drop) для быстрого решения
