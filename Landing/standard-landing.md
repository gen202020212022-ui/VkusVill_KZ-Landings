## 📋 Процесс создания лендинга

### Обязательная последовательность действий:

#### 1. **Запрос типа лендинга** (ПЕРВЫЙ ВОПРОС)
Когда пользователь просит создать лендинг и предоставляет путь к файлу, **ПЕРВЫМ** вопросом должен быть:

**"Какого типа лендинг нужно создать?"**
- **В наличии** - лендинг с остатками товаров и проверкой доступности
- **Под заказ** - лендинг для товаров под заказ (без остатков)

**Важно:** Не начинать проверку файла до получения ответа на этот вопрос!

---

#### 2. **Запрос названия клиента** (ВТОРОЙ ВОПРОС)
После получения ответа о типе лендинга, **ВТОРЫМ** вопросом должен быть:

**"Введите название клиента для кого делаем лендинг?"**

**Особенности:**
- Для типа **"В наличии"** - название клиента **ОБЯЗАТЕЛЬНО**
- Для типа **"Под заказ"** - название клиента **ОБЯЗАТЕЛЬНО**
- Если название клиента не указано при запуске генератора, он должен запросить его автоматически

**Важно:** Не начинать проверку файла до получения названия клиента!

---

#### 3. **Проверка файла на соответствие стандарту** (ТРЕТИЙ ШАГ)
Только после получения ответов на оба вопроса:
1. Тип лендинга
2. Название клиента

Можно приступать к проверке файла на соответствие стандарту.

**Действия:**
- Прочитать файл Excel
- Проверить структуру против стандарта (см. раздел "Стандарт Excel-файла")
- Валидировать с помощью функции `validate_excel_structure()`

**Результаты проверки:**

**✅ Если файл соответствует стандарту:**
- Начать генерацию лендинга
- Использовать указанный тип лендинга
- Использовать указанное название клиента

**❌ Если файл НЕ соответствует стандарту:**
- **НЕ** начинать генерацию
- Указать пользователю **конкретные ошибки**
- Объяснить, **как нужно скорректировать файл**

## 🎯 Типы лендингов

### 1. **В Наличии** (`--type в-наличии`)
- **Описание:** Лендинг с остатками товаров и проверкой доступности
- **Требования:**
  - Обязательная колонка **"Остаток"** (столбец M, индекс 12)
  - Проверка остатков при добавлении в корзину
  - Отображение остатков в карточке товара
  - Отображение доступного товара в корзине
- **Заголовок:**
  - H1: Название клиента
  - Под заголовком: "В наличии на [дата]" (дата генерируется автоматически)

### 2. **Под заказ** (`--type под-заказ`)
- **Описание:** Лендинг для товаров под заказ (без остатков)
- **Требования:**
  - Колонка "Остаток" **НЕ требуется**
  - Нет проверки остатков
  - Нет отображения остатков
- **Заголовок:**
  - H1: Название клиента
  - Под заголовком: "Под заказ [дата]" (дата генерируется автоматически)

## 📋 Стандарт Excel-файла

### Обязательные колонки (для всех типов):

| Столбец | Индекс | Название колонки | Обязательность | Описание |
|---------|--------|------------------|----------------|----------|
| **A** | 0 | `Артикул` | ✅ **ОБЯЗАТЕЛЬНО** | Уникальный ID товара |
| **B** | 1 | `Категория` | ✅ **ОБЯЗАТЕЛЬНО** | Категория товара |
| **D** | 3 | `Наименование` | ✅ **ОБЯЗАТЕЛЬНО** | Название товара (альтернативы: "Наименование товара", "Название") |

### Для типа "В Наличии":
- **M (12):** `Остаток` ✅ Обязательно

### Для типа "Под заказ":
- **M (12):** `Остаток` ❌ Не требуется

### Опциональные колонки (не критичны):

| Столбец | Индекс | Название колонки | Описание |
|---------|--------|------------------|----------|
| **C** | 2 | `Подкатегория` | Подкатегория товара |
| **E** | 4 | `Квант` | Количество единиц в упаковке |
| **F** | 5 | `Штрихкод` | Штрихкод товара |
| **G** | 6 | `Срок годности (cутки)` | Срок годности (альтернативы: "Срок годности (сутки)", "Срок годности") |
| **H** | 7 | `Вес (гр/мл)` | Вес или объем (альтернативы: "Вес, гр (Объём, мл)", "Вес") |
| **I** | 8 | `Цена Партнеру` | Цена для партнера (альтернатива: "Стоимость товара в закупке, с НДС") |
| **J** | 9 | `Рекомендуемая Розничная Цена` | Рекомендуемая розничная цена |
| **K** | 10 | `Ссылка на фото` | URL изображения товара |
| **L** | 11 | `Ссылка на фото.1` | Дополнительная ссылка на фото |

- **Команда:** `python3 Inbox/generate_landing.py "[путь к файлу]" "[название клиента]" "[short-name]" --type [тип]`

### Репозиторий:
- **Название:** `VkusVill_KZ-Landings` (публичный)
- **GitHub Pages:** `https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/`

### Функция валидации:
```python
validate_excel_structure(df, landing_type='обычный')
```

**Параметры:**
- `df` - DataFrame с данными Excel
- `landing_type` - тип лендинга ('в-наличии' или 'под-заказ')

**Возвращает:**
- `is_valid` - True если файл соответствует стандарту
- `warnings` - список предупреждений (некритичные проблемы)
- `errors` - список ошибок (критичные проблемы)

## ⚠️ Важные правила

### 1. Порядок вопросов
- **НИКОГДА** не начинать проверку файла до получения ответов на оба вопроса
- **ВСЕГДА** спрашивать тип лендинга первым
- **ВСЕГДА** спрашивать название клиента вторым

### 2. Валидация файла
- **НИКОГДА** не начинать генерацию при наличии ошибок (errors)
- Предупреждения (warnings) не блокируют генерацию, но я их показываю

### 3. Тип лендинга
- Для "В Наличии" - колонка "Остаток" **ОБЯЗАТЕЛЬНА**
- Для "Под заказ" - колонка "Остаток" **НЕ требуется**

### 4. Название клиента
- **ОБЯЗАТЕЛЬНО** для обоих типов лендингов
- Используется в заголовке H1
- Используется для генерации short_name (имя файла)

### 5. Итоговая ссылка
- **ОБЯЗАТЕЛЬНО** выводить ссылку для клиента в конце
- Формат: `https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/[имя-файла]`
- Ссылка должна быть готова к отправке клиенту
