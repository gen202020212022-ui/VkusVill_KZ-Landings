### Обязательная последовательность действий:

#### 1. **Запрос типа лендинга** (ПЕРВЫЙ ВОПРОС - ОБЯЗАТЕЛЬНО)
Когда пользователь просит создать лендинг и предоставляет путь к файлу, **ПЕРВЫМ** вопросом должен быть:

**"Какого типа лендинг нужно создать?"**
- **В наличии** - лендинг с остатками товаров и проверкой доступности
- **Под заказ** - лендинг для товаров под заказ (без остатков)

**КРИТИЧЕСКИ ВАЖНО:**
- ❌ **НЕ** использовать информацию из названия файла (например, "КП В наличии для Столичного.xlsx")
- ❌ **НЕ** делать предположения типа "Судя по названию файла, тип лендинга: В наличии"
- ✅ **ВСЕГДА** задавать этот вопрос, даже если название файла содержит "В наличии" или "Под заказ"
- ✅ **ЖДАТЬ** ответа пользователя перед переходом к следующему вопросу
- ❌ **НЕ** начинать проверку файла до получения ответа на этот вопрос!

---

#### 2. **Запрос названия клиента** (ВТОРОЙ ВОПРОС - ОБЯЗАТЕЛЬНО)
После получения ответа о типе лендинга, **ВТОРЫМ** вопросом должен быть:

**"Введите название клиента для кого делаем лендинг?"**

**КРИТИЧЕСКИ ВАЖНО:**
- ❌ **НЕ** использовать информацию из названия файла (например, "КП В наличии для Столичного.xlsx" → НЕ предполагать "Столичный")
- ❌ **НЕ** делать предположения типа "Судя по названию файла, клиент: Столичный"
- ✅ **ВСЕГДА** задавать этот вопрос, даже если название файла содержит название клиента
- ✅ **ЖДАТЬ** ответа пользователя перед переходом к проверке файла
- ❌ **НЕ** начинать проверку файла до получения названия клиента!

**Особенности:**
- Для типа **"В наличии"** - название клиента **ОБЯЗАТЕЛЬНО**
- Для типа **"Под заказ"** - название клиента **ОБЯЗАТЕЛЬНО**
- Если название клиента не указано при запуске генератора, он должен запросить его автоматически

---

#### 3. **Проверка файла на соответствие стандарту** (ТРЕТИЙ ШАГ)
Только после получения ответов на оба вопроса:
1. Тип лендинга

Можно приступать к проверке файла на соответствие стандарту.

**Действия:**

**Результаты проверки:**

**✅ Если файл соответствует стандарту:**
- Начать генерацию лендинга
- Использовать указанный тип лендинга
- Использовать указанное название клиента

**❌ Если файл НЕ соответствует стандарту:**
- **НЕ** начинать генерацию
- Указать пользователю **конкретные ошибки**
- Объяснить, **как нужно скорректировать файл**

## 🎯 Типы лендингов

### 1. **В Наличии** (`--type в-наличии`)
- **Описание:** Лендинг с остатками товаров и проверкой доступности
- **Требования:**
  - Обязательная колонка **"Остаток"** (столбец M, индекс 12)
  - Проверка остатков при добавлении в корзину
  - Отображение остатков в карточке товара
  - Отображение доступного товара в корзине
- **Заголовок:**
  - H1: Название клиента
  - Под заголовком: "В наличии на [дата]" (дата генерируется автоматически)

### 2. **Под заказ** (`--type под-заказ`)
- **Описание:** Лендинг для товаров под заказ (без остатков)
- **Требования:**
  - Колонка "Остаток" **НЕ требуется**
  - Нет проверки остатков
  - Нет отображения остатков
- **Заголовок:**
  - H1: Название клиента
  - Под заголовком: "Под заказ [дата]" (дата генерируется автоматически)

## 🔧 Технические детали

### Скрипт генерации:

- **Команда:** `python3 Inbox/generate_landing.py "[путь к файлу]" "[название клиента]" "[short-name]" --type [тип]`

### 🚨 КРИТИЧЕСКИ ВАЖНО: Уникальность лендингов

**Правило:** ВСЕГДА создавать новый лендинг, даже если для клиента уже существует лендинг!

**Причины:**
- Для одного клиента может быть несколько КП с разными датами
- Остатки на складе меняются со временем
- Каждый лендинг должен быть уникальным и доступен по отдельной ссылке

**Индексация лендингов:**
- ✅ **ОБЯЗАТЕЛЬНО** добавлять дату/время создания в `short-name` (третий параметр команды)
- ✅ Формат: `[название-клиента]-[дата]` или `[название-клиента]-[дата-время]`
- ✅ Примеры:
  - `stolichny-20260109` (дата: 2026-01-09)
  - `stolichny-20260109-1430` (дата и время: 2026-01-09 14:30)
  - `dokovil-20260109` (дата: 2026-01-09)

**ЗАПРЕЩЕНО:**
- ❌ Использовать только название клиента без даты/времени (например, `stolichny`)
- ❌ Пропускать создание нового лендинга, если для клиента уже есть лендинг
- ❌ Говорить "Лендинг для этого клиента уже существует" и не создавать новый

**Что делать:**
- ✅ ВСЕГДА создавать новый лендинг с уникальным именем
- ✅ Добавлять дату/время в `short-name` для уникальности
- ✅ Использовать формат: `[название-клиента]-[YYYYMMDD]` или `[название-клиента]-[YYYYMMDD-HHMM]`
