# 📁 Папка Landing

**Назначение:** Хранение стандартов и Excel-файлов для создания лендингов

---

## 📋 Содержимое

- **`standard-landing.md`** - Полный стандарт создания лендингов (все правила, требования, примеры)
- **`[excel-файлы].xlsx`** - Excel-файлы для генерации лендингов

---

## 🚀 Как использовать в новом чате

### Команда для AI:

```
Создай лендинг по стандарту:
- Стандарт: /Users/crocodile/Desktop/Work_temp_by_Seva_Ustinov/Landing/standard-landing.md
- Файл: /Users/crocodile/Desktop/Work_temp_by_Seva_Ustinov/Landing/[имя-файла].xlsx
```

### Что произойдет:

1. AI прочитает `standard-landing.md` (получит все стандарты)
2. AI задаст: "Какого типа лендинг? В наличии или Под заказ?"
3. AI задаст: "Введите название клиента?"
4. AI проверит файл на соответствие стандарту
5. AI сгенерирует лендинг
6. AI выведет: "🔗 Ссылка для клиента: https://gen202020212022-ui.github.io/VkusVill_KZ-Landings/[имя-файла]"

## ✅ Преимущества

1. **Один файл со всеми стандартами** - удобно для нового чата

4. **Стандарты сохранены** - не потеряются
